Multi-monitor Slideshow

A wallpaper slideshow that mixes normal and spanning wallpapers. Wide images stretch across all of your monitors together and ordinary ones show a different image on each, in the same slideshow. Windows can do this; Plasma's built-in Slideshow can't, so this plugin closes the gap.

Features

Spanned and individual images

Spanning folders hold panoramas and dual or triple monitor wallpapers; individual folders hold ordinary wallpapers. Both take turns in one slideshow, and every monitor changes at the same moment.

Any monitors

Any number of monitors, with any resolution, size and height. A spanned image is laid out over your monitors as they're arranged in Display Configuration.

The same size on every monitor

On monitors with different pixel sizes, a spanned image is scaled per monitor, so it keeps its real size and lines continue straight across the bezel. A monitor that reports a wrong size can be corrected.

Full-width wallpapers

A wallpaper as wide as all of your monitors together is detected, and each monitor shows its own part, with the join on the bezel. Anything else is shown as one panorama.

Your order

Random, by name, or by date modified. Images added to your folders are picked up at the next change.

Familiar settings

A settings page like the built-in Slideshow's: folder lists with tickboxes, a thumbnail grid of each folder, and a tooltip on every setting.

Right-click menu

Open Image, Next, Next Individual and Next Spanned on the desktop's menu. Each entry can be hidden.

One set of settings

Change the settings from any monitor; all of them follow. Images crossfade smoothly, like in the built-in Slideshow.

How spanned images are fitted

A spanned image is placed over your monitors as they sit in Display Configuration, then cut to what each monitor covers. With Same physical size on every monitor on, it's placed by the monitors' real sizes instead of their pixel counts.

A full-width image, one as wide as all of your monitors together, is cut into one slice per monitor: a 32:9 image on two 16:9 monitors splits exactly on the bezel.

A panorama, any other image, is scaled to cover all monitors, centered on them. With Always center on the bezel between the monitors, its middle goes on the join between the monitors instead, so a two-part image made for other monitors still splits on the bezel.

Install

From the KDE Store

Right-click the desktop, choose Desktop and Wallpaper…, click Get New Plugins… and search for Multi-monitor Slideshow. It's also on the KDE Store website.

From a release archive

Download multi-monitor-slideshow-<version>.tar.gz from the releases page and run:

kpackagetool6 -t Plasma/Wallpaper -i multi-monitor-slideshow-<version>.tar.gz

Use -u instead of -i to update.

From source

git clone https://github.com/VasilKalchev/plasma-multi-monitor-slideshow.git
cd plasma-multi-monitor-slideshow
utils/deploy.sh

utils/deploy.sh copies the plugin into Plasma's wallpaper folder and restarts Plasma. To update, run git pull and utils/deploy.sh again.

Use

  1. Right-click the desktop and choose Desktop and Wallpaper…
  2. Set Wallpaper type to Multi-monitor Slideshow.
  3. Add folders: Individual folders for ordinary wallpapers, Spanning folders for wide images that go across all monitors.
  4. Choose how often the image changes and in which order, then click Apply.

Hover any setting for an explanation. The README covers every setting, the limitations and troubleshooting.
